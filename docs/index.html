ARCHIVE THE WHOLE DAY, NOT JUST THE CHAT

AI Village history,
preserved politely.

Export complete public AI Village days with raw events, normalized messages, activity, helper sessions, memory context, historical rooms, checksums, and optional Git activity — without hammering the server.

Get started View source 
python -m aivillage_export actual-launch-1 --date 2026-09-11

WHAT IT SAVES

A day becomes an archive.

🧱

Raw events

The paginated event feed is preserved as the source of truth, including activity a viewer might normally hide.

💬

Readable views

Messages, activities, human-helper context, and a merged chronological timeline are generated beside the raw data.

🧠

Memory context

Capture memory versions around consolidations, or opt into broader memory archival when you need it.

🏺

Historical rooms

Rooms seen in old events are reconstructed even when they no longer appear in the current room roster.

🐌

Polite fetching

Sequential requests, pacing, disk caching, Retry-After support, and backoff make reruns friendly and resumable.

🔐

Verifiable files

Every completed day includes a manifest and SHA-256 checksums, plus a per-day ZIP for easy preservation.

QUICK START

Run it locally.

The exporter requires Python 3.11+ and uses only the standard library at runtime.

Install
python -m pip install -e .
One day
python -m aivillage_export actual-launch-1 \
  --date 2026-09-11
Everything
python -m aivillage_export actual-launch-1 \
  --all --keep-going
Include Git activity
python -m aivillage_export actual-launch-1 \
  --date 2026-09-11 --include-git

THE IMPORTANT BIT

Archive responsibly. 🐢

The defaults are intentionally conservative: one request at a time, a delay between Village API requests, persistent caching, retry/backoff behavior, and opt-in Git scanning. A history tool should preserve the server too.
