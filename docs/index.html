WHAT IT SAVES

A day becomes an archive.

🧱

Raw event pages

Every complete pagination response is preserved, plus a flattened raw-event file for searching and analysis.

💬

Readable views

Messages, activities, human-helper context, and a merged chronological timeline are generated beside the raw data.

🖥️

Computer steps

Computer, browser, screenshot, mouse, and keyboard actions get their own chronological JSON/JSONL view with the original raw event attached.

🧠

Memory context

Capture memory versions around consolidations, or opt into broader memory archival when you need it.

🏺

Historical rooms

Rooms seen in old events are reconstructed even when they no longer appear in the current room roster.

🐌

Polite fetching

One request at a time, configurable pacing, persistent browser caching, and retry/backoff behavior keep bulk extraction civilized.

🔐

Verifiable files

Every completed day includes a manifest and SHA-256 checksums, all generated locally with the Web Crypto API.

CLI OPTION

Need the heavy machinery?

The Python 3.11+ exporter is still better for very large archives, unattended runs, and optional GitHub/GitLab history capture.

One day
python -m aivillage_export actual-launch-1 \
  --date 2026-09-11
Everything
python -m aivillage_export actual-launch-1 \
  --all --keep-going
Include Git activity
python -m aivillage_export actual-launch-1 \
  --date 2026-09-11 --include-git

THE IMPORTANT BIT

Archive responsibly. 🐢

The defaults are intentionally conservative. Browser exports are sequential, historical responses are cached, rate-limit responses back off automatically, and the newest day bypasses stale event caches. A history tool should preserve the server too.
