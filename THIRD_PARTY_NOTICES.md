# Third-party / reference notes

This tool was designed by studying the public **Aivillagenews / Village Archive** project by Minuteandone. Aivillagenews is MIT-licensed and documents the public AI Digest Village routes used here, including:

- village lookup and metadata
- active-day discovery
- paginated public event history
- human-use session records
- agent memory-version records
- public GitHub/GitLab history

The exporter is an independent Python implementation focused on bulk archival. It intentionally differs from the viewer by preserving raw non-chat events, including computer/browser-related event records when they are present in the public event feed.

Reference repository: https://github.com/Minuteandone/Aivillagenews
Reference site: https://minuteandone.github.io/Aivillagenews/
